Official Privacy Policy, Terms of Service, and Account & Data Deletion documentation for the **Tablya (طبلية)** mobile application.

`https://asserusama.github.io/TablyaLegal/`

### Direct Section Links for App Stores:
- **Privacy Policy**: `https://asserusama.github.io/TablyaLegal/#privacy`
- **Data Deletion Instructions**: `https://asserusama.github.io/TablyaLegal/#deletion`
- **Terms of Service**: `https://asserusama.github.io/TablyaLegal/#terms`

## 🚀 How to Enable GitHub Pages
1. Go to your repository on GitHub: `https://github.com/asserusama/TablyaLegal`
2. Click on **Settings** → **Pages** (in the left sidebar).
3. Under **Build and deployment** → **Source**, select **Deploy from a branch**.
4. Select branch **`main`** and folder **`/ (root)`**, then click **Save**.
5. Your website will be active within 1-2 minutes!
